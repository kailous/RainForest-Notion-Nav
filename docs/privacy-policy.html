RainForest Navigator 浏览器扩展 · 生效日期：2026 年 9 月 15 日

Privacy Policy · RainForest Navigator browser extension · Effective: September 15, 2026

1. 概述

RainForest Navigator（以下简称"本扩展"）是一款本地化的浏览器新标签页导航工具。本扩展不收集、不上传、不销售任何用户个人数据。所有导航条目、分类与图标数据均仅保存在您本机浏览器中。

2. 我们收集的信息

本扩展不会主动收集任何个人信息，不包含任何分析统计、广告或第三方追踪代码，也不使用 Cookie。

以下数据由您自行创建或导入，并仅存储在本机浏览器的 IndexedDB 本地数据库中：

  • 导航条目（名称、链接、描述、分类）；
  • 站点图标（以 Base64 编码缓存的图片数据）；
  • 扩展设置（例如您配置的同步 API 地址）。

3. 网络请求说明

本扩展默认不进行任何网络通信。仅在您主动触发以下操作时才会发起网络请求：

  • 同步数据：向您在设置中自行填写的 API 地址（默认为 https://nav.rainforest.org.cn/api/getAllData）请求导航数据，用于与本地数据合并；
  • 图标本地化：下载导航条目所指向站点的图标文件，以便离线显示，下载内容仅保存在本机。

除上述两种由您主动发起的请求外，本扩展不会向任何服务器发送数据。

4. 权限使用说明

权限用途
storage允许扩展在浏览器本地存储导航数据与设置（实际数据存放于 IndexedDB）。
activeTab在您当前标签页内提供导航跳转能力。
host_permissions (<all_urls>)仅用于您主动触发的"同步数据"与"图标本地化"请求，以便访问您配置的 API 地址及任意图标来源站点；本扩展不会在后台自动访问这些站点。

5. 数据共享与披露

本扩展不与任何第三方共享、出售或交换数据。由于数据不离开您的设备，我们亦无法访问、读取或恢复您的任何数据。

6. 数据导出与删除

  • 您可以在扩展管理页中将数据导出为 JSON 文件，该文件仅保存到您指定的本地位置；
  • 您可以在管理页"危险区域"中一键清除全部本地数据；
  • 卸载本扩展或清除浏览器数据时，上述本地数据将被一并删除。

7. 儿童隐私

本扩展不面向 13 岁以下儿童收集任何数据，也不包含任何儿童个人信息。

8. 政策变更

若本政策发生变更，更新后的版本将发布在本页面，并随扩展版本更新生效。

9. 联系我们

如对本政策有任何疑问，请通过项目仓库提交 Issue：https://github.com/kailous/RainForest-Nav

Privacy Policy (English)隐私政策（英文译本）

1. Overview概述

RainForest Navigator (the "Extension") is a local-first new-tab navigation tool for your browser. The Extension does not collect, transmit, or sell any personal data. All navigation entries, categories, and icons are stored only on your own device.

2. Information We Collect我们收集的信息

The Extension does not actively collect any personal information. It contains no analytics, no advertising, no third-party tracking code, and does not use cookies.

The following data is created or imported by you and stored exclusively in your browser's local IndexedDB database:

  • Navigation entries (name, URL, description, categories);
  • Site icons (cached as Base64-encoded image data);
  • Extension settings (e.g. the sync API address you configure).

3. Network Requests网络请求说明

The Extension performs no network communication by default. Network requests occur only when you explicitly trigger one of the following actions:

  • Data sync: fetching navigation data from the API address you configured (default https://nav.rainforest.org.cn/api/getAllData) in order to merge it with your local data;
  • Icon localization: downloading icon files of the sites referenced by your entries so they can be displayed offline; downloaded content is stored locally only.

Apart from these user-initiated requests, the Extension sends no data to any server.

4. Permissions权限使用说明

PermissionPurpose
storageAllows the Extension to persist navigation data and settings in the browser (data is actually kept in IndexedDB).
activeTabProvides navigation actions within your current tab.
host_permissions (<all_urls>)Used solely for the user-initiated "sync data" and "icon localization" requests described above; the Extension never contacts these sites in the background.

5. Data Sharing数据共享与披露

The Extension does not share, sell, or exchange data with any third party. Because your data never leaves your device, we are unable to access, read, or recover any of it.

6. Data Export & Deletion数据导出与删除

  • You can export your data as a JSON file, saved only to a location you choose;
  • You can erase all local data at any time from the extension's management page;
  • Uninstalling the Extension or clearing browser data removes all stored data.

7. Children's Privacy儿童隐私

The Extension does not collect any data from children under 13 and contains no children's personal information.

8. Changes to This Policy政策变更

If this policy changes, the updated version will be published on this page and take effect with the corresponding extension release.

9. Contact联系我们

Questions about this policy can be raised as an issue in the project repository: https://github.com/kailous/RainForest-Nav
